# 会議履歴のPDF保存

ホームの保存済み会議の「…」から「PDFとしてダウンロード」を選ぶと、最終要約をHTMLで組版したA4 PDFをダウンロードします。

PDFには会議名・日時、概要、議題、要点、決定事項、未解決事項、次回確認事項、TODOと担当者・期限・完了状態を出力します。文字起こし本文は含めません。最終要約がない場合は作成を案内します。

利用者の承認を受けてhtml2pdf.jsを追加しました。変換はブラウザー内で行います。HTMLの文字列はtextContentで設定します。日本語フォントは利用端末のフォントを使い、レイアウトを画像としてPDFに格納します。PDF内の文字選択・検索には対応しません。

変換前に10万文字と文書高さ14,000pxの上限を確認し、超過時は途中のPDFをダウンロードしません。初回のみ変換ライブラリの読み込みが発生します。

共有操作では引き続き文字起こしを含むテキストを使用します。送信先は端末の共有画面で利用者が選びます。

## 検証

- 合成の長い要約からブラウザーでPDFを生成・ダウンロードし、A4 2ページを画像化して日本語と改ページを確認。
- 要約本文・TODOの表示、文字起こしの除外、HTMLとしての実行防止、要約なしのエラー、変換失敗時の後片付けを自動テスト。
- 実データの共有・削除、実マイクと外部AI APIの呼び出しは実施していません。
- 別ブラウザー・スマートフォンでの実際のPDF保存は手動確認が残ります。
